AWS EC2 Inventory Report
Python automation script that generates a CSV report of EC2 instances using AWS CLI credentials and Boto3.
Features
•	List all EC2 instances
•	Export to CSV
•	Show instance state
•	Show instance type
•	Show IP addresses
•	Error handling
•	Logging
Prerequisites
•	AWS CLI configured
•	Python 3.x
•	Boto3
Install
pip install -r requirements.txt
Run
python ec2_inventory.py
Output
ec2_instance_report.csv
